# ✅ Todo App

A clean and simple Todo app built with **React** and **Tailwind CSS**. Add tasks, mark them as done, edit them, or delete them. Your tasks stay saved even after you refresh the page.

![Todo App](./screenshots/todo.png)

## ✨ Features

- Add new tasks (empty tasks are not allowed)
- Mark tasks as completed (click on the task text)
- Edit tasks inline (Enter to save, Esc to cancel)
- Delete tasks
- Data persists using **localStorage**
- Friendly "No Tasks Yet" empty state

## 🛠️ Tech Stack

- React (Vite)
- Tailwind CSS
- JavaScript (ES6+)

## 🧠 Concepts Used

- `useState` and `useEffect` hooks
- Controlled components (forms and inputs)
- Lazy state initialization
- Array methods: `map`, `filter`, spread operator
- Conditional rendering
- Keyboard events (`onKeyDown`)
- Browser localStorage with `JSON.stringify` / `JSON.parse`

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/jaspreetsingh06/todo-app.git

# Go to the project folder
cd todo-app

# Install dependencies
npm install

# Start the development server
npm run dev
```

Then open the local URL shown in the terminal (usually `http://localhost:5173`).
